# 개인정보처리방침

> 시행일: 2026년 9월 28일
> 최종 수정일: 2026년 9월 28일

ddugi Project (이하 "서비스")는 이용자의 개인정보를 중요시하며, 「개인정보 보호법」을 준수합니다.

---

## 1. 수집하는 개인정보 항목

| 수집 항목 | 수집 목적 | 필수/선택 |
|---|---|---|
| 아이디 | 계정 식별 및 로그인 | 필수 |
| 비밀번호 (해시 저장) | 계정 인증 | 필수 |
| 이름 | 관리자 식별 | 선택 |
| 닉네임 (감자밭) | 피드백 표시 | 선택 |

## 2. 수집 방법
- 이용자가 직접 입력

## 3. 개인정보의 이용 목적
- 서비스 제공 및 계정 관리
- 피드백 수집 및 서비스 개선

## 4. 개인정보의 보유 및 이용 기간
- 서비스 이용 기간 동안 보유
- 회원 탈퇴 또는 삭제 요청 시 지체 없이 파기

## 5. 개인정보의 파기
- 전자적 파일: 복구 불가능한 방법으로 삭제
- 보유 기간 경과 시 지체 없이 파기

## 6. 개인정보의 제3자 제공
- 이용자의 개인정보를 제3자에게 제공하지 않습니다.
- 단, 법령에 의해 요구되는 경우는 예외로 합니다.

## 7. 개인정보의 국외 이전
- 서비스 데이터는 Neon (Singapore 리전) PostgreSQL 서버에 저장됩니다.
- 데이터 전송 시 SSL 암호화를 사용합니다.

## 8. 이용자의 권리
이용자는 다음 권리를 행사할 수 있습니다:
- 개인정보 열람 요청
- 개인정보 정정 요청
- 개인정보 삭제 요청
- 개인정보 처리 정지 요청

## 9. 개인정보 보호를 위한 조치
- 비밀번호: PBKDF2-SHA256 해시 (200,000회 반복) + 랜덤 솔트
- 데이터 전송: SSL/TLS 암호화
- 접근 제한: 관리자/마스터 역할 기반 접근 통제
